# Code 

Accessible, open, and reproducible science is an essential aspect of the scientific method. We strive to publish all the code we develop and use as open-source, typically through [GitHub](https://github.com/jessiepelosi). 

**Code for specific publications/projects:**
* [*Eustenopus villosus* population genomics and GEAs](https://github.com/jessiepelosi/EUVI) (Barker et al., in revision) 
* [Non-native ferns analysis](https://github.com/jessiepelosi/NaturalizedFerns) (Pelosi, Yañez et al., 2026) 
* [*Neomusotima conspurcatalis* genome](https://github.com/jessiepelosi/NeoGenome) (Pelosi et al., 2026)
* [*Lygodium microphyllum* genome](https://github.com/jessiepelosi/LygodiumGenome) (Pelosi et al., 2025)
* [*Vittaria appalachiana* population genomics](https://github.com/jessiepelosi/vittaria_ddRAD) (Pelosi et al. 2025)
* [*Lygodium* phylogenomics](https://github.com/jessiepelosi/LygoPhylo) (Pelosi et al., 2024)
* [GOgetter: organize and summarize GO Slims](https://github.com/jessiepelosi/GOGetter) (Sessa et al., 2023)
* [Genomic consequences of asexual reproduction in ferns](https://github.com/jessiepelosi/vittaria_trans) (Pelosi et al., 2023)
* [Phylotranscriptomics of ferns and whole genome duplications](https://github.com/jessiepelosi/ferntxms) (Pelosi et al., 2022)
* [Fern population genetics meta-analysis](https://github.com/jessiepelosi/fernpopgen) (Pelosi and Sessa, 2021)
* [Octocoral symbiont heat tolerance](https://github.com/jessiepelosi/symbiont_tolerance) (Pelosi, Eaton et al., 2021)
* [Octocoral systematics](https://github.com/jessiepelosi/plexaurids) (Pelosi et al., 2021)
