# Resources #

*Below you will find several different types of resources; hopefully you find them helpful!*

## Genome Repositories
*We produce, help produce, and analyze lots of genomic data in the lab. These genomic resources (usually  genome assemblies and annotations) can be found below.*
- [Fern Genome Browser](https://fernbase.org/)
	- Assembly and annotation data for several fern genomes! Maintained by Fay-Wei Li (Duke University) 
- [*Lygodium microphyllum* ](https://zenodo.org/records/17296295) data repository
	- Assembly and annotation of *L. microphyllum* genome
- [*Pectocarya recruvata*](https://zenodo.org/records/14714947) data repository 
	- Assembly and annotation of *P. recurvata* genome; maintained by  by Poppy Northing (University of Arizona)
- [*Centaurea solsistialis*](https://www.ncbi.nlm.nih.gov/datasets/genome/GCA_030169165.1/) data repository 
	- Assembly and annotation of *C. solsistialis* genome; maintained by NCBI / Katrina Dlugosch (University of Arizona)
- [*Neomusotima conspurcatalis* ](https://zenodo.org/records/17334877) data repository 
	- Assembly and annotation of *N. conspurcatalis* (biological control moth for *L. microphyllum*) genome
- [*Centaurea melitensis*](https://zenodo.org/records/18168578)
	- Assembly and annotation of *C. melitensis* genome; maintained by Anthony Dant (University of Arizona)
